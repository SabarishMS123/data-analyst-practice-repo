<h1 align="center">Data Analyst Practice Repository</h1>

<p align="center">
  A structured repository documenting my journey, projects, and hands-on practice in data analytics and business intelligence using Microsoft Power BI.
</p>

<hr>

<h2>📖 Journey &amp; Overview</h2>

<p>
  This repository captures my step-by-step progress transitioning from raw, unstructured data to polished, executive-ready business intelligence dashboards:
</p>

<ol>
  <li><strong>Data Cleaning &amp; Transformation:</strong> Ingesting raw multi-source files via Power Query, handling missing data, standardizing schemas, and building repeatable ETL transformations.</li>
  <li><strong>Data Modeling:</strong> Structuring normalized schemas (Star Schema), defining robust table relationships, and avoiding bidirectional ambiguity.</li>
  <li><strong>DAX Calculations:</strong> Formulating business logic via Data Analysis Expressions (DAX)—including custom KPIs, time intelligence calculations, conditional aggregations, and dynamic measures.</li>
  <li><strong>Visual Storytelling &amp; UI/UX:</strong> Designing clean, interactive reports with drill-through navigation, cross-filtering, slicers, and structured layouts to facilitate data-driven decision-making.</li>
</ol>
